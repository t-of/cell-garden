# CELL GARDEN — 生まれて消えるマスの模様

マスがまわりの数だけで生まれたり消えたりをくり返す「ライフゲーム」。指で描くか、グライダーなどの有名な形を置いて、動き出す模様を眺める。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/cell-garden/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

もとは「コンウェイのライフゲーム」という数学のしくみ（ルール B3/S23）。

1. マスは「生きている」か「空き」。1 世代ごとに、まわり 8 マスのうち生きているマスを数える。空きのマスは **ちょうど 3** で生まれる。生きているマスは **2 か 3** なら残り、それ以外は消える。
2. 盤を指でなぞると描ける（生きているマスから始めると消せる）。「▶」で動き出す。
3. 下の「かたち」を選んで盤をタップすると、グライダーなどの有名な形を置ける。「回す」で 90° ずつ回せる。

- くり返しに入ったら自動で止まり、何世代ごとのくり返しかを出す（動かなくなった・全部消えたも）。もう一度「▶」で、止めずに動き続ける。
- 「1 世代」で 1 世代だけ進める。「はじめから」で最後に動かし始めたときの盤に戻る。速さは 4 段階。
- 盤は 32・64・128 マスの 3 段階。上下・左右の端はつながっている。大きさを変えると盤は空になる。
- PC ではマウスでなぞって描ける。Space で動かす・止める、→ で 1 世代。
- 最後に選んだかたちが共有の URL（`?p=glider` など）に入る。その URL を開くと、その形を置いた盤で始まる。

| かたち | 起きること |
|---|---|
| グライダー | 4 世代で斜めに 1 マス進む |
| 宇宙船 | 4 世代で横に 2 マス進む |
| ブリンカー | 2 世代ごとに縦と横を行き来する |
| パルサー | 3 世代ごとにくり返す |
| 15 周期 | 10 マスの横一列が、15 世代ごとにくり返す形に育つ |
| R ペントミノ | 5 マスなのに長く暴れる |
| 消える種 | 130 世代で全部消える |
| どんぐり | 7 マスから長く育つ |
| グライダー銃 | 30 世代ごとにグライダーを撃つ（小の盤には入らない） |

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

一度開けば、オフラインでも遊べます。

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

テスト（Node.js、フレームワークなし）:

```sh
node test.mjs
```

| ファイル | 中身 |
|---|---|
| `life.js` | 中身（盤・1 世代・くり返しの見分け・かたち・保存と URL の読み書き）。DOM に触らない |
| `main.js` | 画面と操作・描画・音 |
| `test.mjs` | `life.js` のテスト（かたち 9 つの動き、くり返しの見分け） |

- くり返しの見分け: 1 世代ごとに盤の指紋（32 ビットのハッシュ 2 種類）を作り、「指紋 → 世代」を最大 20,000 世代ぶん覚える。同じ指紋が出たら、その差がくり返しの周期。端がつながった盤では、グライダー 1 つが一周して戻るのに 4 × 盤の幅の世代かかる。
- 盤は 1 マス = 1 点の Canvas を CSS で拡大して描く。格子の線（小の盤だけ）と置く前の影は、画面の解像度の Canvas に重ねる。
- 保存は `cell-garden.settings`（`{ v: 1, size, speed, sound, seenHelp }`）。盤は保存しない。
